Watchlist no push em backgroundA watchlist vive no teu iPhone; o GitHub Actions não consegue ler esse armazenamento local. É preciso exportá-la quando adicionares/removeres empresas que queres monitorizar 24/7.
Como ligar a minha watchlist aos alertas?
  1. Marca normalmente as empresas com ★ Watchlist no Finscanner.
  2. Toca em Exportar watchlist. O iPhone descarrega alert_watchlist.json.
  3. No GitHub abre o repositório Finscanner → data → alert_watchlist.json e substitui o conteúdo pelo ficheiro exportado.
  4. Faz Commit changes. O workflow Insider alerts passa a incluir essa watchlist na execução horária seguinte.

Quando repetir? Só quando alterares a watchlist. O teu portfolio é monitorizado separadamente e não precisa deste passo.
