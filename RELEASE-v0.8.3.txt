Finscanner v0.8.3 — Full Integrity Audit

Purpose
- Repair loading-state regressions.
- Keep the complete lateral navigation intact.
- Restore the Quality × Value opportunity zone.
- Make shell/data loading resilient on GitHub Pages and iOS PWA.
- Use one canonical workflow only: .github/workflows/update-data.yml.

Critical fixes
1. Header no longer stays on “a carregar…” when the user changes tabs while stocks.json is loading.
2. The active tab is rendered when data arrives, even if the user navigated before loading completed.
3. All JSON requests have explicit timeouts and failures are visible.
4. Service Worker cache version bumped and old caches removed; shell uses network-first with safe fallback.
5. Workflow validates generated JSON before publishing and retries safely against concurrent main commits.
6. Removed duplicate/renamed workflow copies to prevent accidental upload to the wrong location.
